# 批改对照图 · 配色与网格方案（唯一权威源）

本文是 gaicuo 对照图（第 6.0 节）**颜色与坐标规格的唯一真源**。SKILL.md 只留判据一句话 + 指向本文。
改动颜色一律改本文，再回头核 SKILL.md 第 6.0 节是否还一致（2026-10-10 广哥定）。

## 0. 为什么单独立文

颜色是「严重度语义」的载体：漏写／写错／写到三档必须一眼可分，且不许对调。
用色一旦散落在正文里描述，弱模型每次都会重新发明一套（本次实测就跑偏成自制粉红）。故把**十六进制值、底色／描边／文字三件套、几何参数**全部写死在这里。

## 1. 三档严重度配色（核心，勿对调）

| 档位 | 含义 | 底色 fill | 描边 stroke | 文字 text |
|---|---|---|---|---|
| 漏写 | 最严重：参考答案里有、用户完全没写 | `#FCEBEB`（红50） | `#A32D2D`（红800） | `#791F1F`（红900） |
| 写错 | 中：写了但错／串岗／稿里无此说法 | `#FAEEDA`（琥珀50） | `#BA7517`（琥珀600） | `#993C1D`（珊瑚600） |
| 写到 | 正常：写到且对上 | `#F1EFE8`（灰50） | `#888780`（灰400） | 主文 `#2C2C2A`／副文 `#5F5E5A` |

**严重度口径（2026-10-09 广哥定）**：漏写＝红（最严重）＞ 写错／串岗＝橙 ＞ 写到＝灰。
浅蓝只是分块框，**不算标记档**。三档颜色**禁止对调**，也禁止改用其它色系。

## 2. 分块框与结构色

| 元素 | 规格 |
|---|---|
| 块外框 | 底 `#E6F1FB`（蓝50）＋ 描边 `#185FA5`（蓝600），`rx="16"`、`stroke-width="0.5"` |
| 块标题 | 字号 14、`font-weight="400"`、色 `#0C447C`（蓝800） |
| 上下分区虚线 | `stroke="#888780"`、`stroke-width="0.5"`、`stroke-dasharray="5 4"` |
| 图例色块 | 三档同上表（底色＋描边），文字用该档 text 色 |
| 说明行／注解行 | 灰底 `#F1EFE8`＋灰描边，文字 `#5F5E5A`、字号 12 |

形态总则：几何扁平、无渐变／无阴影／无圆角装饰（`rx` 6~16 之间取值）；所有颜色**内联硬编码在元素属性上**，禁用 CSS 色类（本项目实测色类不生效，会渲染成黑）。

## 2.5 顶部得分徽标（2026-10-21 广哥定，必出、要显眼）

图**顶部第一行左侧必须是得分徽标**，比正文大一号，让用户一眼看到分数。

| 元素 | 规格 |
|---|---|
| 徽标框 | `x=40`、`y=28`、`w=200`、`h=40`、`rx=10`，底 `#E6F1FB`（蓝50）＋ 描边 `#185FA5`（蓝600）、`stroke-width="0.5"` |
| 分数文字 | 框内 `x=60`、`y=54`（垂直居中），**字号 20**、`font-weight="400"`、色 `#0C447C`（蓝800），写法固定 `得分 N / 10` |
| 区间说明 | 徽标右侧 `x=252`、`y=54`，字号 13、色 `#5F5E5A`，写法 `合理区间 a ~ b：一句话说清为什么在这里` |
| 图例行 | 因顶部多了一行，图例整体下移到 `y=82`（色块 28×16、`rx=4`；色块 `x=40/118/196`，文字 `x=76/154/232`，字号 12）；读图说明 `x=290`、`y=94` |
| 块外框 | 上缘改为 `y = 110`（＝图例底 98 + 12），块标题基线 `y=136`，条目首行 `y=150` |

**分数徽标不是严重度标记**，不参与「红＞橙＞灰」三档，也不许拿三档颜色染它（蓝框恒定）。
分数口径与正文第 1 条评分必须**逐字一致**（含主分与区间）。

## 3. 几何与坐标（可直接照抄）

画布：`<svg viewBox="0 0 680 H" width="100%">`，**680 不可改**，H = 最底部元素 y + 20。
安全区 x=40 到 x=640。字体族 `font-family="var(--font-sans)"` 挂在外层 `<g>`。

| 元素 | 参数 |
|---|---|
| 图例块 | 起于 (40,36)；**本条已被第 2.5 节下移规则覆盖，现行值见 2.5 表（y=82）**，每个色块 52×18、间距 14；末尾接一行读图说明 |
| 块外框 | `x=40`、`width=600`，上缘 `y = 图例行底 + 12`（图例行时 y=66） |
| 块标题基线 | 框上缘 + 26 |
| 条目行 | `x=60`、`width=560`、行高 48、圆角 8、相邻行间距 6（即下一条 `y = 上一条 y + 54`） |
| 条目主文 | 行内 x=74、`y = 行顶 + 18`，字号 13 |
| 条目副文（钩子字／关键词） | x=74、`y = 行顶 + 36`，字号 12、该档浅色 |
| 行右标记 | `x=606`、`text-anchor="end"`，字号 12，写「对／漏／错」 |
| 分区虚线 | 首行条目顶端 −12（即 `y=330`），`x1=60 x2=620` |
| 框底留白 | 末行底 + 10（本次 426 + 10 = 436），H = 436 + 30 = 466 |

行高按内容实际折行数定：单行内容用 48，两行副文用 48，需要三行的（如错误项附展开说明）放到 60，别把短行撑到与长行同高（禁止无关空白）。

## 3.5 关键词加粗（2026-10-21 广哥定，必做）

广哥原话：「做图的时候加上加粗标记，对于错漏的部分的重点关键词，这样我看起来轻松些。」

| 元素 | 规格 |
|---|---|
| 加粗范围 | **漏写（红）与写错（橙）条目**里的采分词／必背关键词 |
| 写法 | 在现有 `<text>` 内就地用 `<tspan font-weight="bold">关键词</tspan>` 包裹，**不拆新行、不改字号、不改颜色** |
| 颜色 | 仍取该档 text 色（红 `#791F1F`、橙 `#993C1D`），**禁止用加粗替代表意、禁止动三档配色** |
| 写到（灰）条目 | **不加粗**（没有错漏要标），保持 400 |
| 每行加粗量 | 主文最多 2 段；副文（关键词行）可整段加粗；不许整句全包（全粗＝没重点） |
| 图例说明 | 图例右侧那行说明写成「粗体字＝该条必背关键词」 |
| 字重 | 关键词用 `bold`（=700），正文一律 400。**不用 500** —— 中文字体普遍没有 Medium 档，`font-weight="500"` 会回落成 400、看起来完全没粗（2026-10-21 广哥实测退回：「我希望的是图片中直接加粗的字体」） |
| ⛔ 禁代替 | **不许用「」【】引号、`·`、下划线等标点代替加粗**，关键词本身也不带括号（广哥原话「你怎么是用个括号括起来了」）——加粗只能用字重表达 |

## 4. 档位归属的判据（与 SKILL.md 第 6.0／6.2 节一致）

1. 条目落在虚线上还是下，看它是「正确／遗漏」还是「写错」：正确与遗漏在线上，写错在线下。
2. 是否正确：过了**简写豁免**（核心关键词写到即算对）的条目 → 灰；关键词本身没写 → 红；写了但词不对／串岗／稿里无此说法 → 橙。
3. 残次项（橙色）只写「错的词 ＋ 原因」，原因前缀 `×`，同一行或下一行跟随；写错项排在块末。
4. 图的红色项必须与文字第 3 块「遗漏关键点」补漏清单**逐条一致**；橙色项与文字第 2 块「错误」的写错项一致（不许单边存在）。
5. 图的箭头／连接线只表示背诵串记顺序时，不参与严重度着色，用灰 `#888780`。

## 5. 自检（画完立刻核）

1. 三档底色／描边／文字是否与第 1 节表格逐字一致（照抄，别凭记忆）？
2. **顶部有没有得分徽标**（字号 20、`得分 N / 10`、蓝框），分数与正文第 1 条评分是否逐字一致？
3. 有没有把漏写与写错的颜色对调？有没有拿其它颜色（粉、紫、绿）当严重度标记？
4. 颜色是否全部内联硬编码（没有任何 `class="c-*"` 承担颜色）？
5. 短行下面有没有与内容无关的大段空白（行高是否按实际折行数给的）？
6. 红色项＝文字补漏清单、橙色项＝文字错误项，两处对齐了吗？
7. **错漏条目里的关键词加粗了吗**（红／橙行内用 `<tspan font-weight="bold">`而非 500、灰行不加粗、加粗没改该档颜色与字号、没有拿括号引号代替粗体）？**全图字重只许 400 / bold 两档**（`font-weight="500"` 在中文字体回落成 400、写了等于没写；块标题与分数徽标一律 400）？
