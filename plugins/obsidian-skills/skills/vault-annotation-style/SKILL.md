# 笔记补注/辨析内容写法

往 <vault> 任意 .md 里**追加/补注**知识点、辨析、做题技巧时，内容样式按本 skill；mechanics（零空行、序号空格、全角标点等）仍过 `vault-write-discipline`。

## 铁律
1. **解释/与上一行相关的内容一律缩进**：补注（做题技巧、辨析、现实政策等）另起缩进行写在原题之下，不与原题挤同一行；缩进层级对齐该笔记已有的子项（如选项 A/B/C/D 的缩进）。
2. **简化突出主要内容与关键辨析点**：一句话能说清的不写两句；核心是"辨析"——把易混概念的对立关系点透，不铺背景。
3. **长段文字分行写**：一段超过两行的补注拆成多条缩进短行（如"做题技巧:"/"辨析:"/"现实政策:"各一行）。
4. **合理加粗**：只加**关键结论词**与**易混对照词**（如 **补贴** vs **津贴**），不加满篇。
5. **不写文号类信息**：杜绝"国人部发〔2006〕61号""人社部发〔2015〕7号"这类发文编号；只保留概念名（如"艰苦边远地区津贴"），聚焦辨析而非出处罗列。
6. **辨析优先于罗列**：目的是让考生分清考点，不是抄法条全文；现实政策只作为"题干问 X 才考虑 Y"的边界提示，不展开。

## 反例（不要这样写）
- 把 做题技巧+现实政策+文号 全挤进原题同一行，且不缩进、不分行、不加粗重点。
- 写"国人部发〔2006〕61号《完善艰苦边远地区津贴制度实施方案》"——文号属冗余，删；只留"艰苦边远地区津贴"。

## 正例骨架
```
<N>. 原题……, 选x (==**答案**==). ==**关键事实**==.
    做题技巧: 题干"依据教师法"+<条件> → 选**X**(第N条).
    辨析: **X**(第N条) ≠ **Y**(第M条); <易混点一句点透>.
    现实政策: 仅当题干问"<边界条件>"才往<概念名>上靠, 那属<制度>非第N条; 本题依教师法仍选X.
```

## 与别的 skill 关系
- mechanics 见 `vault-write-discipline`，本 skill 只管内容样式。
- 链接形态见 `obsidian-jump-line`；补注里要引别的行用其行号链接，不写裸路径。
